# Fast Fast

Application mobile très simple construite avec Expo.

## Lancer avec Expo Go

1. Installer les dépendances avec `npm install`.
2. Lancer `npx expo start`.
3. Ouvrir le projet avec Expo Go.

La version actuelle est une maquette locale : les points sont stockés uniquement pendant la session. Le retrait Airtel Money n'est pas encore connecté à un vrai service de paiement.
